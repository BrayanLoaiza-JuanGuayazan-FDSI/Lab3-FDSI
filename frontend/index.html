Endpoints disponibles — Alerts API

GET/alertsListar todas las alertas
GET/alerts/{id}Detalle de una alerta
GET/alerts/severity/{level}Filtrar por severidad (CRITICAL, HIGH, MEDIUM, LOW)
GET/alerts?status=openFiltrar por estado
POST/alertsCrear nueva alerta (body JSON)

Endpoints disponibles — Actions API

GET/actionsListar todas las acciones registradas
GET/actions/alert/{alert_id}Acciones sobre una alerta específica
POST/actionsRegistrar una acción (investigate / escalate / contain / close / reopen)
